# JEAF X-Fun Test Runtime README #

This repository contains the source code of a test runtime implementation of JEAF X-Fun. It's only intended to be used to test X-Fun API itself but not as runtime environment for unit testing or production.

## Links ##
For further information please refer to:

* [JEAF X-Fun Getting started](https://anaptecs.atlassian.net/l/c/8vuqYGsN)
* [Maven Repository](https://search.maven.org/artifact/com.anaptecs.jeaf.x-fun/jeaf-x-fun-default-runtime)
* [Javadoc](https://javadoc.io/doc/com.anaptecs.jeaf.x-fun/jeaf-x-fun-default-runtime)

## How do I get set up? ##

* Create a clone of this repository on your local machine.
* Execute Maven on the top level project `maven clean install`
